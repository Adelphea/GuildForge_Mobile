# Architecture du Code - GuildForge Mobile

**Auteur :** Manus AI
**Date :** 12 Octobre 2025
**Version :** 1.2
**Tags :** [documentation, technique, architecture, code, godot, gdscript]

Ce dossier détaille les principes fondamentaux de l'**architecture logicielle** du projet GuildForge Mobile. Il couvre les conventions de nommage, la structure du projet Godot, la gestion de l'état du jeu et les principes de design logiciel, assurant une base solide pour le développement et la maintenabilité du code. Une architecture bien définie est cruciale pour la scalabilité et la collaboration au sein de l'équipe.

---

## Contenu du Dossier

Ce dossier est composé de plusieurs documents essentiels pour comprendre et contribuer à l'architecture du code :

*   **[Principes de Design Logiciel](./principes_design_logiciel.md)**
    *   Présente les principes de conception logicielle adoptés pour le projet, incluant la modularité, la séparation des préoccupations et l'approche orientée composants.

*   **[Structure du Projet Godot](./structure_projet_godot.md)**
    *   Décrit l'organisation des fichiers et dossiers au sein du projet Godot.

*   **[Conventions de Nommage du Code](./conventions_nommage_code.md)**
    *   Établit les règles et les meilleures pratiques pour le nommage des variables, fonctions, classes et fichiers GDScript.

*   **[Gestion de l'État du Jeu](./gestion_etat_jeu.md)**
    *   Explique comment l'état global du jeu est géré, y compris les transitions entre les différents états.

*   **[Guide d'Intégration Godot](./guide_integration_godot.md)**
    *   Fournit des directives pour l'intégration de nouvelles fonctionnalités et modules dans l'environnement Godot.

*   **[Vue d'ensemble des Scripts](./vue_ensemble_scripts.md)**
