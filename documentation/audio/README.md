# Documentation Audio - GuildForge Mobile

**Auteur :** Manus AI
**Date :** 12 Octobre 2025
**Version :** 1.2
**Tags :** [audio, design-sonore, musique, UI, UX, ambiance, feedback]

Ce dossier contient la documentation relative à la **Direction Sonore** de GuildForge Mobile. Il détaille les principes de conception pour la musique, les effets sonores (SFX), les sons de l'interface utilisateur (UI), et les outils/workflows audio. L'objectif est de créer une ambiance sonore immersive et cohérente avec le thème médiéval et réaliste du jeu, tout en fournissant un feedback clair au joueur sans être intrusif.

---

## Contenu du Dossier

Ce dossier est structuré pour couvrir les aspects clés de la direction sonore. Chaque section contient un `README.md` pour une navigation plus détaillée :

*   **[Design Sonore](./design_sonore/README.md)**
    *   Détaille l'ambiance sonore générale, les effets sonores (SFX) pour les actions du jeu et le feedback audio de l'interface utilisateur.

*   **[Musique](./musique/README.md)**
    *   Présente les thèmes musicaux, leur rôle dans l'ambiance du jeu et les directives pour leur intégration dans Godot.

*   **[Outils et Workflow Audio](./outils_workflow_audio.md)**
    *   Décrit les outils de production audio utilisés et le workflow recommandé pour l'intégration des assets sonores dans le projet.
