# Déploiement et Tests - GuildForge Mobile

**Auteur :** Manus AI
**Date :** 12 Octobre 2025
**Version :** 1.2
**Tags :** [documentation, technique, deploiement, tests, android, godot]

Ce dossier contient la documentation relative aux processus de **déploiement** et aux stratégies de **test** pour le projet GuildForge Mobile. Il couvre la création de builds Android, la signature d'applications, les méthodes de distribution, ainsi que les différents types de tests et les outils associés. L'objectif est d'assurer la stabilité, la performance et la qualité du jeu sur la plateforme mobile cible.
