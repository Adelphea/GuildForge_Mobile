Ce dossier contient la documentation relative aux stratégies et techniques d'**optimisation des performances** pour le projet GuildForge Mobile. L'objectif est de garantir une expérience de jeu fluide et réactive sur les appareils mobiles, en abordant la gestion de la mémoire, l'optimisation CPU/GPU et les stratégies spécifiques au développement mobile. Une performance optimale est cruciale pour l'engagement des joueurs sur cette plateforme.
