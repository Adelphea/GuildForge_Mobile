# GuildForge_Mobile - Documentation et Développement

Bienvenue sur le dépôt de documentation et de développement de GuildForge_Mobile. Ce projet est structuré autour de trois piliers documentaires principaux pour garantir la clarté et la cohérence :

| Acronyme | Nom Complet | Rôle | Lien |
| :--- | :--- | :--- | :--- |
| **GDD** | Game Design Document | Contenu, règles et expérience de jeu. | [Accéder au GDD](docs/GDD/README.md) |
| **TDD** | Technical Design Document | Architecture logicielle, outils, processus de build et tests. | [Accéder au TDD](docs/TDD/README.md) |
| **PMD** | Project Management Document | Organisation, planification, ressources, risques et aspects légaux/financiers. | [Accéder au PMD](docs/PMD/README.md) |
