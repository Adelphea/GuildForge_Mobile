# Analyse et Justification du Pipeline XML -> Custom Resource

Ce répertoire contient les analyses détaillées, les rapports de progression et les justifications techniques qui ont mené à la conception et à l'implémentation du pipeline de conversion XML vers Custom Resource (CR) décrit dans le TDD-01.

Les documents ici servent de preuve de concept et de traçabilité pour les décisions architecturales majeures, notamment :
- La résolution de l'héritage XML (P1).
- La gestion des références inter-Def (P2).
- Le choix du format `.tres` vs `.res` pour l'optimisation mobile.
- La gestion des types complexes et des données brutes.

Ces fichiers ne sont pas destinés à être lus dans le cadre de la documentation de haut niveau, mais sont essentiels pour toute personne souhaitant comprendre en profondeur les fondations techniques du système de données.
