# Documentation Technique - GuildForge Mobile

**Auteur :** Le seul humain
**Date :** 18 Octobre 2025
**Version :** 1
**Tags :** [documentation, technique, godot, architecture, optimisation, déploiement, développement]

Ce dossier regroupe l'ensemble de la **documentation technique** du projet GuildForge Mobile. Il couvre l'architecture du code, les stratégies d'optimisation des performances, les processus de déploiement et de test, ainsi que la configuration des outils et de l'environnement de développement. L'objectif principal est de fournir une référence complète et claire pour les développeurs travaillant sur le projet, garantissant la qualité, la maintenabilité et l'efficacité du code.
