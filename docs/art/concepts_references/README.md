# Concepts et Références - GuildForge Mobile

**Auteur :** Manus AI
**Date :** 12 Octobre 2025
**Version :** 1.1
**Tags :** [art, concepts, références, personnages, environnement, inspiration]

Ce dossier contient les concepts artistiques et les références visuelles qui ont guidé le développement de GuildForge Mobile. Il sert de base pour l'inspiration et la cohérence artistique, en s'assurant que tous les éléments visuels du jeu s'alignent avec la vision médiévale et réaliste du projet.

Ce dossier est organisé en deux sections principales :

*   **[Références Environnement](./references_environnement.md)**
